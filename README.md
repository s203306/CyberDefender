# CyberDefender

CyberDefender to edukacyjna gra typu Serious Game, której celem jest nauka rozpoznawania i reagowania na zagrożenia cyberbezpieczeństwa.

## Opis gry

Gracz wciela się w administratora bezpieczeństwa niewielkiej firmy. Jego zadaniem jest monitorowanie sieci komputerowej, analizowanie incydentów oraz podejmowanie decyzji ograniczających skutki cyberataków.

## Główne funkcjonalności

- Interaktywna mapa sieci komputerowej
- Symulacja zagrożeń, takich jak phishing i malware
- Analiza alertów i logów
- Działania obronne: skanowanie, izolacja i blokada
- System oceny decyzji i raport końcowy

## Technologie

- Java
- JavaFX
- JSON
